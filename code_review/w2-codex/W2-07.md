# W2-07 validation

Await rejects concrete non-awaitable names and fields. Stored coroutine values retain their wrapper and unwrap on await. Coroutine shorthand and the three-argument Coroutine annotation compare their result payloads. Returning a coroutine where an Awaitable/Coroutine is expected suppresses missing_await. Decorated definitions are excluded from provably-sync checks. Async callee detection reads the current binding's signature, so a callable parameter shadowing a module-level async function is not spuriously wrapped.

The new await regression was run against W2-06 and failed. All 677 checker tests, Rust 1.94.1 fmt/clippy and CLI build pass. Corpus outcomes match W2-06: 1,481 units, 1,222 accepted, 259 rejected, only the previously confirmed kwargs-callable TypeError differs from the original baseline. Imported async metadata remains W3's responsibility; expression checks consume its resulting coroutine types.
