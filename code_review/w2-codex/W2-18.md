# W2-18 validation

Defaulted data classes warn about slot descriptors only when the class-level field is actually accessed. Resolved scope bindings exclude parameters shadowing the class name. The warning names the accessed field and displays its actual default, including None. A lazily cached module scan avoids repeating a whole-module traversal for every declaration.

ResultErrorMismatch retains its diagnostic code and now describes both returned and propagated Err values. Its shared diagnostics dependency is included in this isolated branch, with general help rather than question-mark-only wording.

Final full corpus: 1481 units, 1216 accepted / 265 rejected; rejection set matches W2-17. An earlier overlapping build caused one transient SIGKILL; the final corpus ran against one fixed binary, with no transient failures.
