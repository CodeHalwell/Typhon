# W2-16 validation

Getter-only properties reject writes, including unknown values; writable setters provide assignment types and getter types remain correct on reads. Cached properties retain Python's writable semantics. ClassVar writes must target the class. Explicit dataclasses without slots and subclasses inheriting an instance dictionary accept undeclared attributes; ordinary slotted classes retain the existing error. The tuple_variadic read-view lattice change landed in W2-05.

The regression failed before the fix. Controls cover writable/cached properties, bare dataclass, slots=False, inherited plain classes and class-level ClassVar assignment.
