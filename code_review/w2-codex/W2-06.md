# W2-06 validation

Callable values retain positional arity and defaults. Source-provenance lookup supplies parameter names/kinds for known definitions, aliases and lambdas; a structural Callable contract without names cannot bind positional slots by keyword. `**kwargs` does not absorb extra positional arguments. Class descriptors provide constructor signatures in Callable contexts without making their instances callable. ParamSpec binds and substitutes the full actual parameter shape, including defaults. Calls through unions of functions/lambdas check every variant and join return types.

The failing regression was run before the fix. Rust 1.94.1 fmt, all 676 checker tests, clippy and CLI build pass.

Corpus: 1,481 units, 1,222 accepted, 259 rejected. One newly rejected unit: `stress/round-2026-09-01/types/h22_kwargs_callable.ty`. CPython 3.13 confirms `TypeError: only_one() takes 1 positional argument but 2 were given`. All other outcomes match the baseline. W5 owns the baseline file; this unit should be added with that runtime justification.

Follow-up: ParamSpec callable returns preserve their source parameter names/kinds/defaults, including g(a=1). Class descriptor aliases are distinguished from instances and accepted in Callable factory contexts; ClassVar descriptor aliases use the same provenance. The new regression failed before the fix and passes afterward. 695 checker unit tests, fmt, clippy and CLI build pass; all 1481 corpus outcomes match W2-18.
