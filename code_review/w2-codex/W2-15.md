# W2-15 validation

Mutable interface fields are invariant and require writable implementations. Frozen classes and getter-only properties cannot supply them; writable properties remain supported. Read-only interface properties retain covariance and field implementations. Method contracts preserve keyword parameter names and kinds, while extra defaulted implementation parameters are accepted.

The regression failed before the fix. Three old fixtures claiming mutable-field covariance/getter-only conformance were corrected to invariant or explicitly read-only contracts. Rust 1.94.1 fmt, 688 checker tests, clippy and CLI build pass.
