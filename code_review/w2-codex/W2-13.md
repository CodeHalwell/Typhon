# W2-13 validation

Newtype member inference delegates to its base's method contracts while retaining user-defined methods. String methods return str/list[str], so a lower() result cannot silently satisfy Email. Distinct string newtypes are rejected by the existing mixing diagnostic for addition, as numeric newtypes already were.

The regression failed before the fix. Rust 1.94.1 fmt, 685 checker tests, clippy, CLI build and unchanged W2-12 corpus pass: 1,481 units, 1,219 accepted, 262 rejected.
