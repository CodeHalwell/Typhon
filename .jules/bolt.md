## 2024-05-24 - [Optimize duplicate class name checking allocations]
**Learning:** In the `tyc/crates/tyc-types` crate, `collect_classes_and_functions` traverses the AST. Inside the hot loop processing `Stmt::ClassDef`, it was unnecessarily allocating `String`s by calling `cd.name.as_str().to_owned()` just to perform a check against a local `HashSet<String>` (`seen_class_names`).
**Action:** Use `HashSet<&str>` to borrow the strings directly from the AST nodes and prevent unnecessary heap allocations in hot paths. Only call `.to_owned()` if the persistent structure (like `Checker::classes` or `Checker::class_parents`) strictly requires an owned string.
