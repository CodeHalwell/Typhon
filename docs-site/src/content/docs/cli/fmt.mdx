```
tyc fmt [PATHS]... [--check]
```

Parses `.ty` files, validates the syntax, normalises a small set of whitespace rules, and writes the result back to disk.

:::caution[v1 scope]
The v1 formatter is a line-level whitespace pass, not yet a full AST-based reprinter. It collapses interior whitespace and tidies bracket/comma spacing, but leaves spacing around `:`, `=`, and `->` alone (those rules need bracket-depth awareness for slices vs annotations). A Typhon-aware AST-based reprinter wrapping `ruff format` is a Phase-5 follow-up.
:::

## Examples

```bash
tyc fmt src/                  # format every .ty in src/
tyc fmt src/main.ty           # format one file
tyc fmt --check src/          # exit 1 if anything would change (CI mode)
```

## What it changes today

- **Interior whitespace** — runs of 2+ spaces past the leading indent are collapsed to one (`def    main` → `def main`).
- **Bracket adjacency** — `(  x` → `(x`, `x  )` → `x)`, `x   ,` → `x,`.
- **Trailing whitespace** — removed.
- **Line endings** — `\n`.

## What it preserves

- **Leading indentation** — 4-space indents are passed through verbatim.
- **Spacing around `:`, `=`, `->`** — left as-is (needs slice/annotation disambiguation; deferred).
- **String quotes** — left as-is (Typhon doesn't take a side between `"` and `'`).
- **`let` / `mut`** placement.
- **Comments** — preserved on the line they appear.

## Flags

| Flag | Effect |
|------|--------|
| `--check` | Exit 1 if any file would change. No writes. |
| `--diff` | Print a unified diff instead of writing. |
| `--quiet` | Suppress per-file output. |

## CI integration

```yaml
- name: Format check
  run: tyc fmt --check src/
```

## Pre-commit

```yaml
# .pre-commit-config.yaml
repos:
  - repo: local
    hooks:
      - id: tyc-fmt
        name: tyc fmt
        entry: tyc fmt
        language: system
        files: \.ty$
```

## What about `tyc fmt` on `.dty`?

Yes — `.dty` files format with the same rules. The bodies are signatures, but the lexer / printer treat them like `.ty`.
