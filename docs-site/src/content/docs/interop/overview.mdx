Typhon's whole pitch is "static safety on top of Python's runtime." That means *talking to Python* is a first-class concern, not an edge case. This section maps every way `.ty` and `.py` interact.

## Mixed-language projects

`.ty` and `.py` interoperate freely. You can:

- Migrate a single file at a time.
- Keep generated code (protobuf, gRPC) as `.py`.
- Use `.ty` for new code, `.py` for legacy.

Plain `.py` files in `src/` are copied to `build/` unchanged. They can import from emitted modules and vice versa. Imports from a plain `.py` are treated as if they crossed an `unsafe:` boundary unless an authored `.dty` overrides them.
