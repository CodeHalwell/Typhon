```toml
[emit]
class-default = "dataclass"
format = true
skip-decoration-bases = []
model-extra = "forbid"
traceback-remap = false
```

| Key | Type | Default | Description |
|-----|------|---------|-------------|
| `class-default` | `"dataclass"` \| `"pydantic"` | `"dataclass"` | Default emission target for `class` declarations. Overridable per-class via the `model` keyword. |
| `format` | bool | `true` | Post-process emitted `.py` through `ruff format`. |
| `skip-decoration-bases` | list of strings | `[]` | Extra base-class names that suppress the automatic `@dataclass(slots=True)` decorator. |
| `model-extra` | `"forbid"` \| `"ignore"` \| `"allow"` | `"forbid"` | Value for `ConfigDict(extra=…)` injected into every `model` class. |
| `traceback-remap` | bool | `false` | Inject a runtime `sys.excepthook` into the entry module so uncaught-exception tracebacks point at `.ty` source instead of emitted `.py`. |

## `class-default`

- `"dataclass"` — `class Foo:` emits `@dataclass(slots=True)`. The recommended default — performance-cheap, no PyPI dependency.
- `"pydantic"` — `class Foo:` emits a Pydantic `BaseModel(extra="forbid")`. Use when *every* class in the project crosses a trust boundary. (Rare.)

You can mix both freely regardless of the default. `class` follows the default; `model` always emits Pydantic.

Unknown values (`"struct"`, `"plain"`, `"regular"`, `"none"`, the empty string, …) are rejected at config load with `tyc::invalid_config_value` and the allowed-values list. They used to be silently treated as `"dataclass"`, which made typos invisible.

## `format`

When `true` (default), emitted `.py` is post-processed through `ruff format` for consistent style. Off is occasionally useful when you want to see the raw printer output for debugging.

## `skip-decoration-bases`

The compiler already auto-skips `@dataclass(slots=True)` for the stdlib bases that conflict with it (`Enum`, `IntEnum`, `StrEnum`, `Flag`, `IntFlag`, `ABC`, `ABCMeta`), plus `Protocol`, `TypedDict`, and `NamedTuple`. `skip-decoration-bases` extends that list with project-specific bases:

```toml
[emit]
skip-decoration-bases = ["BaseModel", "App", "TestCase"]
```

The match is on the **last identifier segment**, so `"App"` catches both `class T(App):` and `class T(textual.App):` regardless of how the base is imported. With this list set, you can write the plain `class` keyword for framework subclasses without reaching for `class!` or `plain class`.

Auto-skip drops only the decorator — it does *not* synthesise an `__init__`. Reach for `class! Foo(Base):` when you also want a synthesised constructor calling `super().__init__()`, or `plain class Foo:` for "no decorator, no synthesised init, body emits verbatim."

## `model-extra`

Controls the `extra` argument in the auto-injected `model_config = ConfigDict(extra=…)` for every `model` class.

| Value | Runtime behaviour |
|-------|-------------------|
| `"forbid"` (default) | Unknown fields raise `ValidationError`. Recommended for public APIs. |
| `"ignore"` | Unknown fields are silently dropped. |
| `"allow"` | Unknown fields are accepted and surfaced as extra attributes on the model instance. |

```toml
[emit]
model-extra = "allow"   # trust all incoming JSON
```

The value affects every `model` class in the project. To override for a single class, write `model_config = ConfigDict(extra="…")` directly in the class body — the desugarer skips injection when a `model_config` statement is already present.

## `traceback-remap`

**Off by default.** When `true`, the emitter injects `typhon_runtime.traceback.install()` at the top of the entry module's `if __name__ == "__main__":` block. The installed `sys.excepthook` loads the emitted `.py.map` sidecars and rewrites each frame of an uncaught-exception traceback from the emitted `.py` back to the corresponding `.ty` source — the same mapping [`tyc trace`](/Typhon/cli/trace/) applies, but automatically and without a separate command.

```toml
[emit]
traceback-remap = true
```

It only touches the **entry** script — library imports never trip the `__main__` guard, so imported modules are left byte-for-byte unchanged. On any failure (missing sidecar, malformed map) the hook falls back to the previously-installed `sys.excepthook`, so it can only ever improve a traceback, never suppress one.

<Aside type="note">
  Default-off keeps existing projects and runtime-free entry points byte-for-byte unchanged. A project with no other runtime feature stays free of the generated `typhon_runtime/` package; enabling this knob is what pulls the runtime in for the entry module.
</Aside>

## Always-on behaviour

One emit policy that was previously documented is no longer configurable:

- **PEP 561 `.pyi` stubs** are always emitted for every `.dty` file.
