## The 30-second pitch

> Every `.ty` file emits valid, idiomatic `.py`. Not all `.py` is valid Typhon.

Typhon is what Python could look like if you started over with three decades of language-design hindsight, while still keeping every Python library you love. It is a *compile-to-Python* language in the same sense that TypeScript is a *compile-to-JavaScript* language: you write the stricter, safer, more ergonomic dialect, and the compiler hands you idiomatic CPython that runs everywhere Python runs — no Typhon runtime, no PyPI dependency, no special interpreter.

<Tabs syncKey="pitch">
  <TabItem label="Typhon">

```python
type LoadError = NotFound | Timeout

class NotFound:
    path: str
class Timeout:
    after_ms: int

def load(path: str) -> Result[str, LoadError]:
    try:
        with open(path) as f:
            return Ok(f.read())
    except FileNotFoundError:
        return Err(NotFound(path=path))

def main() -> None:
    match load("config.toml"):
        case Ok(body):
            print(body)
        case Err(NotFound(path)):
            print(f"missing: {path}")
        case Err(Timeout(after_ms)):
            print(f"timed out after {after_ms}ms")
```

  </TabItem>
  <TabItem label="Emitted Python">

```python
from dataclasses import dataclass
from typhon_runtime import Ok, Err

@dataclass(slots=True)
class NotFound:
    path: str

@dataclass(slots=True)
class Timeout:
    after_ms: int

LoadError = NotFound | Timeout

def load(path: str) -> Ok[str] | Err[LoadError]:
    try:
        with open(path) as f:
            return Ok(f.read())
    except FileNotFoundError:
        return Err(NotFound(path=path))

def main() -> None:
    match load("config.toml"):
        case Ok(body):
            print(body)
        case Err(NotFound(path)):
            print(f"missing: {path}")
        case Err(Timeout(after_ms)):
            print(f"timed out after {after_ms}ms")
```

  </TabItem>
</Tabs>

The match on `LoadError` is statically exhaustive — add a third variant to the union and every match site goes red until you handle it. That is, in one screenshot, the kind of safety Typhon brings to Python.

## What you get

<CardGrid>
  <Card title="Non-nullable by default" icon="approve-check">
    Plain `T` cannot hold `None`. Use `T?` when you mean optional. Flow narrowing on `is None`, `is not None`, `isinstance`, `guard`, and early returns.
  </Card>
  <Card title="No implicit Any" icon="warning">
    Untyped values are a hard error outside `unsafe:` blocks. The strictness is stronger than TypeScript's `noImplicitAny`.
  </Card>
  <Card title="Errors as values" icon="puzzle">
    `Result[T, E]`, `Ok`, `Err`, and the `?` operator make failure visible in signatures — without giving up Python's exception bridge.
  </Card>
  <Card title="Sealed unions + exhaustive match" icon="setting">
    `type Shape = Circle | Rectangle | Triangle`. Add a variant; every `match` lights up red. Refactor with confidence.
  </Card>
  <Card title="Explicit async, smarter concurrency" icon="rocket">
    `gather:` lowers to `asyncio.TaskGroup` (the safe default). `go f(x)` spawns fire-and-forget through a strong-ref registry. No GC'd tasks.
  </Card>
  <Card title="Build-time configuration" icon="seti:config">
    `comptime let PORT: int = int(env("PORT", "8080"))` inlines at build time. Missing required env vars fail the build, not production.
  </Card>
  <Card title="Clean output, no runtime tax" icon="document">
    Emits idiomatic Python you can read, debug, and ship. The handful of helpers (`Result`, `lazy`, task registry) is generated locally as `typhon_runtime/`. No PyPI install.
  </Card>
  <Card title="One binary, full pipeline" icon="terminal">
    `tyc` is the compiler, formatter, language server, REPL, in-process VM, migrator, debugger launcher, and package-manager surface — sub-100ms incremental feedback via Salsa.
  </Card>
</CardGrid>

## Status

Phases 0 through 3 of the [roadmap](/Typhon/project/roadmap/) are complete. **Phase 5 — interop and developer experience — shipped in [v0.1.6](https://github.com/CodeHalwell/Typhon/releases/tag/v0.1.6)**. **Phase 5.5 — constructor / method arity safety — shipped in [v0.2.0](https://github.com/CodeHalwell/Typhon/releases/tag/v0.2.0)** (`tyc::arg_count` on constructors and `impl` methods, cross-module shape propagation, `tyc::missing_field_init` audit for the `X.__new__(X)` bypass). **Phase 6 — Python-annoyances surface — shipped in [v0.3.0](https://github.com/CodeHalwell/Typhon/releases/tag/v0.3.0)** (`newtype`, `freeze let`, `pub`, `blocking_in_async` / `resource_not_managed` / `div_by_zero_literal` diagnostics, cross-platform install). **[v0.4.0](https://github.com/CodeHalwell/Typhon/releases/tag/v0.4.0)** is a type-checker correctness sweep on top of a third stress round (bool ⊆ int, subclass-constructor inheritance, dotted-attribute annotations, container-literal escape detection, De Morgan narrowing, triple-quoted round-trip). **[v0.5.0](https://github.com/CodeHalwell/Typhon/releases/tag/v0.5.0)** is the post-v0.4 roadmap sweep: Salsa cache shared across the LSP check path, `tyc debug` reads in full Typhon coordinates, dict-comp parallelisation, the `Type::TypeConstructor` foundation for higher-kinded types, `comptime` types-as-values, three new `tyc migrate` rewrites, and an opt-in PyPI corpus sweep harness. **Current release: [v0.5.1](https://github.com/CodeHalwell/Typhon/releases/tag/v0.5.1)** — a correctness + tooling point release on top of v0.5.0: three emit-correctness fixes (triple-quote whitespace tracker, `case Ok(...)` pattern walk for the `typhon_runtime` auto-import, duplicate `__typhon_Err__` alias dedupe), a deep VS Code TextMate grammar audit closing ~18 miscolorings, and 22 new stdlib-only examples (47–68) with emitted `.py` companions for examples 01–46 alongside. The minimum-viable language — non-null types, sealed unions, `Result`, dataclass emit — is shippable today.

Typhon targets CPython 3.13+ (and the free-threaded 3.13t/3.14t builds when you opt in). It is not a new runtime, not a Mojo-style separate language, and not a replacement for the Python you already write. It is the language you reach for when you want Python's libraries with Rust-flavoured static safety and ergonomics.
